# Business Model Canvas

| Bloque | Contenido |
|---|---|
| Socios clave | Proveedores de reputación, cloud, comunidades de ciberseguridad, universidades y organizaciones educativas como socios potenciales; no existen acuerdos confirmados. |
| Actividades clave | Investigación, mantenimiento de reglas, evaluación de calidad, desarrollo seguro, educación, soporte y validación comercial. |
| Recursos clave | Equipo interdisciplinario, motor explicable, interfaz, taxonomía de fraude, infraestructura, marca y conocimiento local. |
| Propuesta de valor | Identificar señales de posibles estafas en mensajes y enlaces, explicar el riesgo en lenguaje claro y sugerir próximos pasos sin exigir conocimientos técnicos. |
| Relación con clientes | Autoservicio guiado y educativo; soporte en planes pagos; onboarding y reportes agregados para equipos. |
| Canales | Web, contenido educativo, buscadores, comunidades, universidades y venta directa a PyMEs; todos salvo la web son hipótesis. |
| Segmentos | Prioritario: adultos digitalmente activos no expertos que reciben mensajes financieros/comerciales. Secundario: PyMEs sin equipo de seguridad dedicado. |
| Costos | Desarrollo, cloud, APIs, seguridad, cumplimiento, soporte, contenido, adquisición y capacitación. |
| Ingresos | Freemium; suscripción personal; licencia por organización/usuarios; capacitación. Precios y disposición a pagar pendientes de validar. |

## Coherencia y riesgos

El acceso gratuito favorece adquisición y misión; las funciones avanzadas y de equipo sostienen ingresos. El riesgo principal es que los usuarios prefieran herramientas gratuitas existentes o que una tasa alta de falsos positivos destruya confianza. Se debe validar antes de invertir en integraciones costosas.
